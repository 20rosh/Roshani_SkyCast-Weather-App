# 🌤️ SkyCast – Weather Forecast Application

A modern, responsive weather forecasting web application that provides real-time weather information, current atmospheric conditions, and a 5-day forecast for cities around the world.

**SkyCast** makes checking the weather simple, fast, and convenient with a clean interface, location-based weather updates, and dynamic weather backgrounds.

🔗 **Live Website:** [View SkyCast](https://20rosh.github.io/Roshani_SkyCast-Weather-App/)

🔗 **GitHub Repository:** [Roshani_SkyCast-Weather-App](https://github.com/20rosh/Roshani_SkyCast-Weather-App)

## ✨ Features

- 🌍 **City Search:** Search for weather information by city name.
- 📍 **Current Location:** Get weather updates using your device's geolocation.
- 🌡️ **Real-Time Weather:** View current temperature and weather conditions.
- 📅 **5-Day Forecast:** Check upcoming weather conditions.
- 🌤️ **Dynamic Backgrounds:** Weather-based visual backgrounds.
- 🌡️ **Temperature Conversion:** Switch between Celsius and Fahrenheit.
- 🔍 **Search History:** Access recently searched cities using Local Storage.
- ⚠️ **Weather Alerts:** Receive alerts for extremely high temperatures.
- 📱 **Responsive Design:** Works across desktop, tablet, and mobile devices.
- ❌ **Input Validation:** Displays helpful messages for empty or invalid searches.

## 🌐 API Integration

SkyCast uses the free [Open-Meteo API](https://open-meteo.com/) to retrieve weather information.

The application uses weather data services for:

- Current weather conditions
- Temperature information
- Weather codes and descriptions
- Forecast information

No API key is required for the standard Open-Meteo public API endpoints used by this project.
